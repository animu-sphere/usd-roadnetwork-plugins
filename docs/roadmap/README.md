# Roadmap

| Document | Use it for |
| --- | --- |
| [Release plan](release-plan.md) | Phases, their goals and exit criteria, and the format acceptance gate. |
| [Current work](current.md) | Open work and exit criteria for the active phase. Use issues and PRs for task-level tracking. |
| [Backlog](backlog.md) | Unscheduled work with an owner and a condition for revisiting it. |

Move a work item between the current view and the backlog when its scope
changes. Keep completed work in [release records](../releases/) or
[reports](../reports/). For current support, use the
[capability matrix](../reference/CAPABILITY_MATRIX.md). See the
[documentation index](../README.md) for ownership and maintenance rules.
